Java 基本数据类型与自动转换：八种基本类型按取值范围从小到大为 byte、short、int、long、float、double、char、boolean。小范围类型赋给大范围类型自动转换（如 int 转 long），大范围转小范围必须强制转换且可能丢失精度（如 double 转 int 截断小数）。整数字面量默认 int，小数字面量默认 double，因此 float f=1.5 必须写成 1.5f。char 与 int 可互相运算，char c='A'+1 结果是 'B'。运算中 byte、short、char 参与算术运算时自动提升为 int，这也是 byte b=1; b=b+1 编译报错而 b+=1 通过的原因。

String 与 StringBuilder 的区别：String 是不可变对象，每次拼接都会创建新对象，循环中大量拼接会产生大量临时对象，效率低下。StringBuilder 内部维护可扩容的字符数组，append 直接在原数组上修改，循环拼接应使用 StringBuilder，最后 toString 转回 String。StringBuffer 与 StringBuilder 接口相同，但方法加了 synchronized 锁，是线程安全的，单线程场景性能略低。字符串相等判断必须用 equals 而不是 ==，== 比较的是引用地址，equals 比较内容；字符串常量池机制会让内容相同的字面量指向同一对象，但这不适用于 new 出来的对象。

面向对象三大特性详解：封装通过 private 修饰属性、提供 public 的 getter/setter 实现，可以在访问器中加入校验逻辑，如 setAge 时拒绝负数。继承使用 extends 关键字，子类拥有父类的非私有属性和方法，Java 只支持单继承，但可以多层继承，所有类的最终父类是 Object。多态的三个前提：继承或实现关系、方法重写、父类引用指向子类对象；调用重写方法时执行的是子类实现（运行时多态），但成员变量和静态方法没有多态性，编译和运行都看左边类型。instanceof 用于运行时判断对象的真实类型，向下转型前必须先判断，否则可能抛出 ClassCastException。

ArrayList 与 LinkedList 的选择：ArrayList 底层是动态数组，支持随机访问，按下标 get/set 时间复杂度 O(1)；中间插入删除需要移动后续元素，复杂度 O(n)；扩容机制为容量不足时扩为原来的 1.5 倍并整体复制。LinkedList 底层是双向链表，头尾插入删除 O(1)，但随机访问需要从头或尾遍历，复杂度 O(n)。实际开发中绝大多数场景选 ArrayList，因为 CPU 缓存对连续内存更友好；需要频繁在头部插入删除或用作队列/栈时选 LinkedList。遍历 ArrayList 用 for 循环效率高，遍历 LinkedList 应使用迭代器。

HashMap 的工作原理：HashMap 基于 hash 表存储键值对，JDK8 中结构为数组+链表+红黑树。put 时先对 key 的 hashCode 做扰动再与数组长度取模得到下标；发生哈希冲突时以链表形式追加，链表长度超过 8 且数组长度达到 64 时转为红黑树，查询效率从 O(n) 提升到 O(logn)。默认初始容量 16，负载因子 0.75，元素数量超过容量乘负载因子时扩容为两倍并重新分布。key 的自定义类必须正确重写 hashCode 和 equals，否则相同内容的两个对象会被视为不同的 key。需要保证遍历顺序时使用 LinkedHashMap，需要按 key 排序时使用 TreeMap。

常见排序算法的特征：冒泡排序逐趟比较相邻元素并交换，时间复杂度 O(n²)，稳定，适合教学与小数据量。选择排序每趟选出最小元素放到已排序末尾，复杂度 O(n²)，不稳定，交换次数最少。插入排序像整理扑克牌，将新元素插入已排序部分的合适位置，对基本有序的数据效率接近 O(n)，稳定。快速排序选定基准元素将数组分为两部分递归处理，平均复杂度 O(nlogn)，不稳定，是最常用的通用排序。归并排序先分后合，稳定且保证 O(nlogn)，但需要 O(n) 额外空间。面试和笔试中常考各算法的平均复杂度、最坏复杂度与稳定性三个维度。
